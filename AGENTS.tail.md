## This repo specifically

- **API:** Arcads external API (`https://external-api.arcads.ai`).
- **Auth:** HTTP Basic via `ARCADS_BASIC_AUTH` (pre-encoded `Basic ...` header) or `ARCADS_API_KEY` as the Basic password. Values in `.env` must be **single-quoted** due to special characters.
- **Skills:**
  - `arcads-external-api` — main API reference (endpoints, auth, polling, asset routing).
  - `generate-youtube-thumbnail` — YouTube thumbnail batch workflow on top of the Nano Banana 2 image endpoint.
  - **Image-ad ecosystem** (3 skills + shared 37-template library) — see [shared/skills/image-ad-prompting/OVERVIEW.md](shared/skills/image-ad-prompting/OVERVIEW.md):
    - `chatgpt-image-ad` — generate via Arcads `gpt-image-2` (typography / UI-mimicry creatives)
    - `nano-banana-image-ad` — generate via Arcads `nano-banana-2`/`-pro`/`-edit` (photoreal / lifestyle creatives)
    - `image-ad-clone` — single backend-agnostic skill that reverse-engineers existing ads into reusable templates (asks which backend to validate against at Phase 1; optionally cross-validates at Phase 8)
- **Setup check:** `./scripts/check-arcads-env.sh`.

## Cursor Cloud specific instructions

- **What this repo is:** a skill pack of Python (stdlib-only) + bash scripts that call the **Arcads external API**. There is **no server/dev-server, no build step, and no test suite or linter config**. "Running the app" means invoking a generator script (e.g. `python3 skills/chatgpt-image-ad/scripts/generate_image.py --prompt ... --aspect-ratio 1:1`) or a workflow bash script — each run hits the live Arcads API.
- **Credentials are required for any real generation.** Set `ARCADS_BASIC_AUTH` (preferred, a full `Basic ...` header) or `ARCADS_API_KEY` in `.env`. Without a valid key, scripts still reach the live API and return **HTTP 403** (network egress works; only auth is missing). The connectivity check is `./scripts/check-arcads-env.sh`.
- **The generator scripts require a `.env` FILE to exist** — `load_env()` raises if `.env` is absent, even when creds are in the shell environment. Create it via `./scripts/setup.sh` or `cp .env.example .env`, then put the real key in it. Caveat: a leftover placeholder `ARCADS_BASIC_AUTH` value in `.env` takes precedence over a shell env var, so replace/remove the placeholder if you rely on env-var creds.
- **`./scripts/setup.sh` is interactive** (prompts for the API key with hidden input). In non-interactive/automation contexts, pipe empty input to skip the prompt: `printf '\n' | ./scripts/setup.sh`. It also creates `MASTER_CONTEXT.md` and syncs skills into `.claude/skills/` and `.cursor/skills/` (both gitignored, regenerated by `./scripts/sync-skill.sh`).
- **Optional per-workflow dependencies** (not needed for core image/video generation): `meta-ad-builder` needs `requests` + `python-dotenv` (`shared/skills/meta-ad-builder/scripts/requirements.txt`, installed by the update script); `caption-video` needs `openai-whisper` (heavy pip install) + `npx hyperframes`; the Pixar/claymation pipelines need `ffmpeg` + `jq`. `ffmpeg`, `jq`, `node`, and `python3` are already on the base image.
